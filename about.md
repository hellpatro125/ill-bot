# ILLBot (Impossible Levels Suite)

**ILLBot** is a high-performance Geometry Dash botting, autoclicking, physics manipulation, and verification suite built for **Impossible Levels (ILL)** and extreme level creation.

## Key Features

- **Silicate Aesthetic GUI**: Sleek frosted dark burgundy/crimson interface with sidebar navigation, modern toggle switches, dynamic tab panels, and instant preset buttons.
- **Dual Autoclicker**:
  - Independent **Player 1** & **Player 2** autoclickers.
  - Granular CPS adjustment from **1.0 CPS to 2000.0 CPS** (supporting insane micro-clicks for ILL straight flying and spam).
  - Mode selection: Continuous spam or Hold-to-click.
- **TPS Changer & Speedhack**:
  - Real-time physics TPS modification: presets for **240, 360, 480, 1000, 2000, 50000 TPS**.
  - Built-in Speedhack multiplier (`0.1x` to `2.0x`) for frame-by-frame analysis and testing.
- **Replay Macro (Record & Playback)**:
  - Exact frame-based input recording and playback for P1 and P2.
  - Save and load `.json` macro files.
- **Trajectory Visualizer**:
  - Parabolic jump arc, wave diagonal, and ship curve predictions.
  - Real-time hazard collision detection with **Pink Death Box** indicators at points of failure.
- **Hitbox Visualizer**:
  - Color-coded bounding boxes for player, hazards (spikes, saws), and solid blocks.

## Hotkeys

- `Tab` or `F` or `Left Alt`: Toggle the ILLBot Menu.
